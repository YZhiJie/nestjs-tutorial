14. 认证与授权（JWT） ​

对应漫画

本章配套四格漫画：EP.14 JWT 认证授权（含剧情回顾、知识点拆解、坑点清单与自测题）

本章示例：server/src/ch14-auth（npm run start:ch14 → http://localhost:3014）

本章说明 ​

第 9 章用静态令牌表演示了守卫机制，本章升级为生产级形态：

  • 认证（Authentication）：用户名 + 密码登录，签发 JWT（JSON Web Token）；后续请求凭 Authorization: Bearer <token> 访问；
  • 授权（Authorization）：JWT payload 中携带角色，RolesGuard 按 @Roles() 元数据做角色控制；
  • 口令安全：scrypt 加盐散列存储，比较用 timingSafeEqual 防时序攻击。

演示账号：admin / admin123（admin 角色）、demo / demo123（user 角色）。

代码实现 ​

口令散列 ​

使用 Node 内置 crypto.scrypt（无需原生依赖），格式 salt:hash：

ts
// 文件: server/src/ch14-auth/auth/password.util.ts
// 口令散列：使用 Node 内置 crypto.scrypt（无需原生依赖）；
// 格式 salt:hash，比较时用 timingSafeEqual 防时序攻击
// 生产环境推荐 bcrypt/argon2（抗 GPU/ASIC 更强），接口语义相同
import { randomBytes, scryptSync, timingSafeEqual } from 'node:crypto';

export function hashPassword(plain: string): string {
    const salt = randomBytes(16).toString('hex');
    const hash = scryptSync(plain, salt, 64).toString('hex');
    return `${salt}:${hash}`;
}

export function verifyPassword(plain: string, stored: string): boolean {
    const [salt, hash] = stored.split(':');
    const candidate = scryptSync(plain, salt, 64);
    const expected = Buffer.from(hash, 'hex');
    return candidate.length === expected.length && timingSafeEqual(candidate, expected);
}

认证服务 ​

ts
// 文件: server/src/ch14-auth/auth/auth.service.ts
import { Injectable, UnauthorizedException } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { hashPassword, verifyPassword } from './password.util';
import type { Role } from './roles.decorator';

export interface JwtPayload {
    sub: number; // 用户 ID（JWT 标准字段）
    username: string;
    role: Role;
}

interface UserRecord extends JwtPayload {
    passwordHash: string;
}

@Injectable()
export class AuthService {
    constructor(private readonly jwtService: JwtService) {}

    // 演示用户表（教学用内存存储；生产请落库）。密码以 scrypt 散列保存
    private readonly users: UserRecord[] = [
        { sub: 1, username: 'admin', role: 'admin', passwordHash: hashPassword('admin123') },
        { sub: 2, username: 'demo', role: 'user', passwordHash: hashPassword('demo123') },
    ];

    async login(username: string, password: string) {
        const user = this.users.find((u) => u.username === username);
        // 统一报错文案，避免暴露「用户不存在」还是「密码错误」（防账号枚举）
        if (!user || !verifyPassword(password, user.passwordHash)) {
            throw new UnauthorizedException('用户名或密码错误');
        }
        const payload: JwtPayload = { sub: user.sub, username: user.username, role: user.role };
        return {
            accessToken: await this.jwtService.signAsync(payload),
            tokenType: 'Bearer',
            expiresIn: 3600,
        };
    }
}

JWT 认证守卫 ​

ts
// 文件: server/src/ch14-auth/auth/jwt-auth.guard.ts
// JWT 认证守卫：解析 Authorization: Bearer <token>，验签后把 payload 挂到 req.user
import { CanActivate, ExecutionContext, Injectable, UnauthorizedException } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import { JwtService } from '@nestjs/jwt';
import type { Request } from 'express';
import { IS_PUBLIC_KEY } from './public.decorator';
import type { JwtPayload } from './auth.service';

export type AuthedRequest = Request & { user: JwtPayload };

@Injectable()
export class JwtAuthGuard implements CanActivate {
    constructor(
        private readonly jwtService: JwtService,
        private readonly reflector: Reflector,
    ) {}

    async canActivate(context: ExecutionContext): Promise<boolean> {
        const isPublic = this.reflector.getAllAndOverride<boolean>(IS_PUBLIC_KEY, [
            context.getHandler(),
            context.getClass(),
        ]);
        if (isPublic) return true;

        const request = context.switchToHttp().getRequest<AuthedRequest>();
        const token = this.extractToken(request);
        if (!token) {
            throw new UnauthorizedException('缺少 Authorization: Bearer <token>');
        }
        try {
            // verifyAsync：验签 + 校验过期时间；失败抛错
            request.user = await this.jwtService.verifyAsync<JwtPayload>(token);
        } catch {
            throw new UnauthorizedException('令牌无效或已过期');
        }
        return true;
    }

    private extractToken(request: Request): string | undefined {
        const [type, token] = request.headers.authorization?.split(' ') ?? [];
        return type === 'Bearer' ? token : undefined;
    }
}

模块装配 ​

JwtModule.register({ global: true }) 让 JwtService 全局可注入；全局守卫链先认证后授权：

ts
// 文件: server/src/ch14-auth/auth/auth.module.ts
import { Module } from '@nestjs/common';
import { APP_GUARD } from '@nestjs/core';
import { JwtModule } from '@nestjs/jwt';
import { AuthService } from './auth.service';
import { AuthController } from './auth.controller';
import { JwtAuthGuard } from './jwt-auth.guard';
import { RolesGuard } from './roles.guard';

// 教学用固定密钥；生产必须从环境变量注入（见第 15 章配置管理）
export const JWT_SECRET = process.env.JWT_SECRET ?? 'dev-only-secret-do-not-use-in-prod';

@Module({
    imports: [
        JwtModule.register({
            global: true, // JwtService 全局可注入，业务模块无需重复 imports
            secret: JWT_SECRET,
            signOptions: { expiresIn: '1h' },
        }),
    ],
    controllers: [AuthController],
    providers: [
        AuthService,
        // 全局守卫链：先认证（我是谁），后授权（我能做什么）
        { provide: APP_GUARD, useClass: JwtAuthGuard },
        { provide: APP_GUARD, useClass: RolesGuard },
    ],
    exports: [AuthService],
})
export class AuthModule {}

控制器 ​

ts
// 文件: server/src/ch14-auth/auth/auth.controller.ts
import { Body, Controller, Get, Post, Req } from '@nestjs/common';
import { IsString, MinLength } from 'class-validator';
import { AuthService } from './auth.service';
import { Public } from './public.decorator';
import type { AuthedRequest } from './jwt-auth.guard';

class LoginDto {
    @IsString()
    username!: string;

    @IsString()
    @MinLength(6)
    password!: string;
}

@Controller('auth')
export class AuthController {
    constructor(private readonly authService: AuthService) {}

    // POST /auth/login —— 免登录（@Public），成功返回 JWT
    @Public()
    @Post('login')
    login(@Body() dto: LoginDto) {
        return this.authService.login(dto.username, dto.password);
    }

    // GET /auth/profile —— 登录即可，返回令牌中解析出的用户信息
    @Get('profile')
    getProfile(@Req() req: AuthedRequest) {
        return req.user;
    }
}

// 文件: server/src/ch14-auth/users/users.controller.ts
import { Controller, Get, Req } from '@nestjs/common';
import { Roles } from '../auth/roles.decorator';
import type { AuthedRequest } from '../auth/jwt-auth.guard';

@Controller('users')
export class UsersController {
    // GET /users/me —— 任意登录用户
    @Get('me')
    me(@Req() req: AuthedRequest) {
        return { message: '当前登录用户', user: req.user };
    }

    // GET /users —— 仅 admin 角色
    @Roles('admin')
    @Get()
    findAll() {
        return [
            { id: 1, username: 'admin', role: 'admin' },
            { id: 2, username: 'demo', role: 'user' },
        ];
    }
}

最佳实践与坑点 ​

  1. JWT 密钥必须从环境变量注入：process.env.JWT_SECRET（本章留有开发兜底值，生产缺密钥应直接拒绝启动，配置管理见第 15 章）；密钥泄露 = 任何人可伪造任意用户；
  2. 令牌过期时间要短（本章 1h），配合 refresh token 机制续期；不要把有效期设成几天；
  3. 口令绝不明文存储：scrypt/bcrypt/argon2 加盐散列；比较用 timingSafeEqual 防时序侧信道；
  4. 登录失败文案统一：「用户名或密码错误」，不暴露账号是否存在；
  5. payload 最小化：只放 sub/username/role 等必要字段——JWT 是签名不加密的，payload 可被任何人 base64 解码，绝不放敏感信息；
  6. @Public() 只给真正公开的接口（登录、注册、健康检查），默认全部受保护。
